# Second Brain Campus

A student-focused personal college intelligence dashboard. It connects subjects, tasks, notes, deadlines and uploaded resources in one workspace.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Deploy
Upload the contents of this folder to a GitHub repository and import it into Vercel. Framework preset: Next.js. No environment variables required.

## Prototype limitations
This is a frontend prototype. Data is saved in the current browser using localStorage. The assistant uses demo logic, and file uploads are represented as local resource entries. Real AI, document extraction, cross-device sync, authentication and shared integrations require backend services.
